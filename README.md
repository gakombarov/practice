# Распознавание рукописных символов EMNIST

## 1. Описание решения

- **Тип задачи:** Многоклассовая классификация изображений (рукописные буквы и цифры).
- **Данные:** Датасет `EMNIST` (сплит `'balanced'`), включающий 112 800 обучающих и 18 800 тестовых изображений размером 28x28 пикселей. Всего 47 классов.
- **Модель:** Многослойный перцептрон `MLPClassifier` из библиотеки `scikit-learn`.
- **Предобработка:** Масштабирование значений пикселей в диапазон [0, 1] путем деления на `255.0` и изменение формы массивов в 2D-векторы `(N, 784)`.
- **Гиперпараметры:**
  - `hidden_layer_sizes=(256, 128)`
  - `max_iter=30`
  - `random_state=42`
- **Метрики на тестовых данных:**
  - **Точность (Accuracy):** **83.28%** (требование 68% выполнено).
  - **Анализ ошибок:** Модель чаще всего путает заглавную букву `'F'` со строчной `'f'` (153 раза). Наибольшее количество ошибок приходится на символ `'q'`.

---

## 2. Установка и запуск сервиса

Сервис построен на базе веб-фреймворка **FastAPI** и отдает интерфейс для рисования и распознавания символов.

### Вариант 1. Запуск через Docker

```bash
# 1. Клонирование репозитория
git clone <ссылка_на_ваш_репозиторий>
cd practice

# 2. Сборка Docker-образа
docker build -t emnist-app .

# 3. Запуск Docker-контейнера
docker run -p 8000:8000 emnist-app
```

### Вариант 2. Локальный запуск через Uvicorn

```bash
Bash
pip install -r requirements.txt
uvicorn myapp.main:app --port 8000
```
